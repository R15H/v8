# Building and Testing V8

## Prerequisites

- Python 3
- Git
- `depot_tools` (Google's build tooling, provides `gclient`, `gn`, `ninja`)
- C++20 compatible compiler (Clang recommended)
- ~10 GB disk space for a full build

## Fetching Dependencies

V8 uses the Chromium `depot_tools` workflow for dependency management:

```bash
# Fetch all dependencies specified in DEPS
gclient sync
```

## Build System

V8 uses **GN** (Generate Ninja) as its primary build system. GN generates Ninja build files.

### Configuration

```bash
# Generate build files for a release build
gn gen out/release --args='is_debug=false'

# Generate build files for a debug build
gn gen out/debug --args='is_debug=true'

# Common build arguments
gn gen out/x64.release --args='
  is_debug=false
  target_cpu="x64"
  v8_enable_webassembly=true
  v8_enable_i18n_support=true
'
```

### Key Build Arguments (from `gni/v8.gni` and `BUILD.gn`)

| Argument | Default | Description |
|----------|---------|-------------|
| `is_debug` | `true` | Debug build with assertions |
| `target_cpu` | host | Target architecture (`"x64"`, `"arm64"`, etc.) |
| `v8_enable_webassembly` | `true` | WebAssembly support |
| `v8_enable_i18n_support` | `true` | ICU internationalization |
| `v8_enable_turbofan` | `true` | TurboFan optimizing compiler |
| `v8_enable_maglev` | `true` | Maglev mid-tier compiler |
| `v8_enable_pointer_compression` | varies | Compress 64-bit pointers to 32-bit |
| `v8_enable_sandbox` | varies | Security sandbox |
| `v8_enable_lite_mode` | `false` | Lightweight mode (no optimizing compiler) |
| `v8_optimized_debug` | `true` | Optimizations even in debug mode |
| `v8_enable_verify_heap` | debug | Heap verification checks |
| `v8_enable_disassembler` | debug | Machine code disassembly |

### Building

```bash
# Build everything
ninja -C out/release

# Build just d8 (the V8 shell)
ninja -C out/release d8

# Build with Siso (faster, if available)
# V8 sets use_siso=true by default in .gn
autoninja -C out/release d8
```

### Bazel Build (Alternative)

```bash
# V8 also supports Bazel builds
bazel build //:d8 --config=v8
```

Configuration in `BUILD.bazel`, `MODULE.bazel`, and `.bazelrc`.

## Running V8

```bash
# Run a JavaScript file
./out/release/d8 script.js

# Interactive REPL
./out/release/d8

# With flags
./out/release/d8 --trace-gc script.js       # Trace garbage collection
./out/release/d8 --print-bytecode script.js  # Print generated bytecode
./out/release/d8 --prof script.js            # CPU profiling
./out/release/d8 --trace-opt script.js       # Trace optimization decisions
./out/release/d8 --trace-deopt script.js     # Trace deoptimizations
```

## Testing

### Test Runner

V8 uses a Python-based test runner:

```bash
# Run all tests
python3 tools/run-tests.py --outdir=out/release

# Run specific test suites
python3 tools/run-tests.py --outdir=out/release mjsunit
python3 tools/run-tests.py --outdir=out/release cctest
python3 tools/run-tests.py --outdir=out/release unittests
python3 tools/run-tests.py --outdir=out/release test262
```

### Test Suites

| Suite | Location | Type | Description |
|-------|----------|------|-------------|
| `mjsunit` | `test/mjsunit/` | JavaScript | Main JavaScript unit tests |
| `cctest` | `test/cctest/` | C++ | C++ component tests using custom framework |
| `unittests` | `test/unittests/` | C++ | Google Test (gtest) based unit tests |
| `test262` | `test/test262/` | JavaScript | ECMAScript specification conformance |
| `inspector` | `test/inspector/` | Mixed | Chrome DevTools Protocol tests |
| `wasm-spec-tests` | `test/wasm-spec-tests/` | WebAssembly | WASM specification compliance |
| `wasm-js` | `test/wasm-js/` | JavaScript | WASM-JavaScript interop tests |
| `intl` | `test/intl/` | JavaScript | Internationalization tests |
| `message` | `test/message/` | JavaScript | Error message output verification |
| `webkit` | `test/webkit/` | JavaScript | WebKit compatibility tests |
| `mozilla` | `test/mozilla/` | JavaScript | Mozilla compatibility tests |
| `js-perf-test` | `test/js-perf-test/` | JavaScript | Performance benchmarks |
| `fuzzer` | `test/fuzzer/` | C++ | Fuzzing harnesses |
| `bigint` | `test/bigint/` | JavaScript | BigInt feature tests |
| `benchmarks` | `test/benchmarks/` | JavaScript | Performance benchmarks |

### Running Specific Tests

```bash
# Run a single mjsunit test
./out/release/d8 test/mjsunit/test-file.js

# Run cctest with filter
./out/release/cctest --gtest_filter="*TestName*"

# Run unittests with filter
./out/release/unittests --gtest_filter="*TestName*"

# Run test262 with specific test
python3 tools/run-tests.py --outdir=out/release test262 --test=built-ins/Array/from
```

### Building Test Targets

```bash
# Build C++ test executables
ninja -C out/release cctest
ninja -C out/release unittests
ninja -C out/release v8_fuzzer
```

## Snapshot Generation

V8 pre-compiles built-in functions at build time into a "snapshot" for fast startup:

```bash
# The snapshot is built automatically as part of the build
# The tool is: mksnapshot (src/snapshot/mksnapshot.cc)
ninja -C out/release mksnapshot

# Snapshot configuration
# v8_enable_fast_mksnapshot=false  (speed vs quality)
# v8_enable_concurrent_mksnapshot=true  (parallel snapshot building)
```

## Profile-Guided Optimization

```bash
# PGO profiles for builtins are managed in tools/builtins-pgo/
# Download profiles:
python3 tools/builtins-pgo/download_profiles.py

# Build with PGO:
gn gen out/release --args='v8_builtins_profiling_log_file="path/to/profile"'
```
